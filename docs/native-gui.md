# 原生桌面客户端

默认界面由 [C++ 和 Qt Widgets](../native-qt/main.cpp) 实现，作为单个原生进程运行，使用 Wayland 与桌面交互。它复用现有 Node 后端、官方账号网页和项目独立 Wi-Fi Direct 助手，不嵌入浏览器。原 Slint 客户端保留为可选入口 `./tools/run-slint.sh`。

从项目根目录启动界面：

```sh
./tools/run-native.sh
```

`npm run ui` 和 `npm run scan` 也调用此入口。启动时会通过 CMake 检查并构建，依赖 Node.js、C++17 编译器、CMake、pkg-config、FUSE 3 开发库、Qt 6 Widgets/Network/DBus 和 Qt Wayland 平台插件；普通文件拖出还需可用的 `/dev/fuse` 与 `fusermount3`，扫码需要 `qrencode`。界面自动启动并等待后端就绪，退出程序时停止由它启动的后端。如果对应端口上已有使用相同状态目录的后端，界面会复用它，退出时不会停止该后端。多个界面复用同一个自动启动的后端时，启动后端的那个界面退出会停止它。

默认从 `.vivo-connect/config.json` 读取本机访问凭据，支持 `--state-dir`、`--port` 和 `VIVO_STATE_DIR`、`PORT`。凭据仅发送至本机后端，不写入 GUI 日志。可用 `--quit-after 秒数` 进行短时启动检查。

## 使用

- 左侧显示设备、账号状态和传输记录，可断开、重连或通过二维码添加设备。Wi-Fi Direct 默认通过系统授权启动临时助手，退出程序时清理其网络；可选[一次安装系统服务模式](backend.md#一次安装的系统服务模式)，之后不再请求授权，退出 GUI 或后端短暂重启时保留服务的组。
- 桌面系统托盘可用时，关闭主窗口会隐藏到托盘，手机连接、文件传输和剪贴板同步继续运行。点击托盘图标或选择“打开软件”恢复窗口；右键菜单可切换当前设备的剪贴板同步或选择“退出”结束程序。若桌面没有可用托盘，关闭窗口会退出程序。
- 勾选侧栏“开机后台启动”，桌面登录后会启动后端和托盘，按已有设备设置自动重连；取消勾选即可关闭。若启动时系统托盘不可用，会显示主窗口。该设置属于当前用户，卸载前可取消勾选；也可以删除 `~/.config/autostart/<桌面标识>.desktop`（如果设置了 `XDG_CONFIG_HOME`，则位于该目录的 `autostart` 下）。开机连接仍受手机授权和 Wi-Fi Direct 服务状态限制。
- 成功连接的设备由后端以私有文件保存；后端启动或手机意外离线后，会自动重连仍可达且授权有效的设备；Wi-Fi Direct 历史设备可经官方同账号蓝牙预连接重新建链，无需重复扫码。左侧显示等待重连、正在重连或需要授权；“断开连接”也可暂停离线设备的重试，“重新连接”恢复重试，需要授权时可重新扫码。设备列表右键可忘记设备。失败不再自动弹扫码；详见[自动重连边界](backend.md#保留设备的断连与重连)。
- “Wi-Fi Direct 设置”可查看、启用、更新或移除可选系统持久服务。启用时选择无线网卡并完成一次系统授权；服务绑定当前用户、状态目录和后端端口。更新已安装服务会重新启动其网络。服务管理仅从 pacman 安装的 root 管理文件启动，源码目录运行时请先安装软件包。服务和组可跨客户端退出保留；重启电脑或无线网络重建后，手机仍可能需要重新扫码。
- 左侧“同步文本剪贴板”控制当前选中设备的文本双向同步，连接后使用后端的会话设置；暂停会清除该会话的同步缓存。支持最多 64 KiB 的 UTF-8 文本，不同步文件或图片。切换设备或重新连接时不会主动发送电脑已有的剪贴板内容；手机可能需要开启互联剪贴板权限。KDE Wayland 下使用 Klipper 获取后台剪贴板变化，其他 Wayland 环境的后台读取取决于桌面环境的权限与 Qt 支持。
- 默认位置为手机共享存储 `/storage/emulated/0/`，不是 Android 系统根目录。支持搜索当前目录、多选、右键重命名、移动、删除、新建文件夹和查询目录大小。删除前需要确认。
- 电脑文件可以拖入当前手机目录或某个手机文件夹，也可以通过“上传文件”选择。手机文件和文件夹可以直接拖出，拖到电脑时按复制处理并保留手机原文件：确认放下后文件管理器开始读取时，后台先接收完整文件并校验，再交给文件管理器复制，传输期间请保持界面和手机连接。取消拖动或在手机文件列表内放下不会触发接收。
- 文件夹内的手机文件可拖动到其他手机文件夹移动。接收单个文件也可通过“接收所选文件”选择保存位置；传输记录可查看状态与取消任务。
- 传输记录显示准备、传输、校验及通知手机等阶段，并分别列出文件总大小和已传输的 TAR 数据量。归档包含额外头部，二者不能直接相除计算精确百分比。若文件已保存但完成通知失败，记录会显示该状态，并可打开接收目录。

快捷键：`Alt+←` 或鼠标后退键后退，`Alt+→` 或鼠标前进键前进，`Alt+↑` 上一级，`F5` 刷新，`Ctrl+L` 编辑路径，`Ctrl+F` 搜索。焦点位于文件列表时，可用 `Backspace` 上一级、`Delete` 删除、`F2` 重命名、`Enter` 打开或接收，以及 `Ctrl+A` 全选。删除前仍会要求确认。

拖出暂存文件保留在后端状态目录的 `downloads` 中，与普通接收任务一致。按需读取不等于流式复制：目标文件管理器读取时会等待完整接收和校验，大文件可能暂时不显示复制进度，且目标程序可能有自己的读取超时。GUI 不将完整文件载入内存；实际收发、校验和大小限制由后端管理。

## 验证与内存

```sh
./tools/test-native-qt.sh
npm test
```

Qt 自检覆盖本机接口鉴权、电脑文件拖入事件和拖出 URI 的两种读取方式。手机实测中，电脑到手机的拖入传输完成，修正 URI 格式后手机文件拖到电脑文件管理器成功。Wayland 窗口通过协议事件检查。

2026-11-02 在本机实测，单个 Qt GUI 在连接本机后端、显示文件列表时稳定 PSS 约 **51 MiB**，RSS 约 **106 MiB**；随后实际使用中约为 PSS 46–54 MiB，正式窗口连接手机后的采样约为 PSS 46 MiB、RSS 104 MiB。PSS 按共享内存比例计算，Node 后端、桌面、无线助手和临时文件选择器另计。之前的 Slint 软件渲染窗口 PSS 约 28 MiB，但其 Winit Wayland 后端缺少跨应用文件拖放。正常使用仅运行一套 GUI。
