# 原子笔记云同步

主界面新增“原子笔记云同步”标签页。登录与手机相同的 vivo 账号，在手机原子笔记中开启云同步，点击“立即同步”。不需要手机近场连接。

## 使用方法

- 同步笔记索引、笔记本、摘要、更新时间、附件关联及回收站。首次按页拉取，后续按版本增量更新。勾选“自动同步（每分钟）”可在现有后端运行期间自动更新索引，设置按账号保存，不新增后台进程或系统服务。
- 按笔记本筛选，搜索标题／摘要；选择笔记后按需读取正文并缓存。已读正文可从缓存打开，尚未读取的正文仍需网络。
- 查看普通富文本。原版图片、手写或其他 `vnote-*` 组件显示附件提示，可从下方列表导出原附件；不自动运行或打开附件。
- “导出文本”保存当前可见正文为 UTF-8 文本；不是含图片、手写及全部原子组件的完整笔记备份。
- 新建普通文本笔记到“未分类”；普通文本笔记可以直接编辑；带样式、图片或附件的笔记使用“编辑笔记文字”，在可直接输入的文字区域中修改并保留原有 HTML 标签、属性、原子组件和附件关联。图片笔记没有现成文字时，也可追加文字说明。输入作为文字转义，不当成脚本执行。
- 仅含文字但带简单样式的笔记可在连续文本编辑区中编辑；更改正文并保存前会提示，确认后将转换为纯文字，原有样式不保留。含图片、附件或复杂组件的笔记仍使用保留结构的文字编辑方式。
- 可以改名、移入回收站及恢复。移入回收站和恢复会先确认；不提供永久删除和清空回收站。

图片、附件和富文本笔记支持修改普通文字，不能直接修改图片、手写画布、样式或原子组件内部数据。手写画布笔记仍需官方客户端编辑；加密笔记仅显示锁定条目，不读取正文、不尝试绕过官方解锁。

保存前重新同步并比较打开时的版本；操作完成后回读云端确认。若其他设备已更新，保留当前会话的未保存草稿并提示刷新；重新打开编辑器时，如云端版本已变化，普通文本会询问是否载入旧草稿；富文本旧草稿可复制到剪贴板手动合并，不将过期文字片段自动套用到新版本。草稿只在当前进程内存中保留，退出客户端后不保留；不支持离线写入队列，也不会自动重试不确定是否成功的云端写入。

## 本地数据和预览

每个账号的数据分别保存在状态目录 `notes/<账号 SHA-256>/`，索引、设置及正文缓存采用私有权限。只有整轮分页和回收站快照完整成功后才原子提交索引与版本。部分分页失败、游标不推进、非法响应或版本回退均保留旧索引。

正文和附件关联按笔记版本、资源版本及索引重建代次缓存；读取正文前后校验笔记版本，避免把读取期间发生变更的内容存入缓存。附件校验后按资源版本独立保存，不用旧附件冒充新版本。切换账号会隔离索引、缓存和自动同步设置。

预览使用 Qt 文本文档，不执行 JavaScript，禁用正文链接自动打开，并同时在浏览器控件与文档层禁止外部网络及本地文件资源读取。正文中的远程图片和 `file:` 路径不会直接加载。

## Windows 原版协议

依据本地 Windows `v7.0.6.0-cn` 样本的 `app-modules-note.js`；调用点、加密头及回收站语义保存在[协议证据](../evidence/notes/official-reference.txt)。当前支持中国区账号，网关为 `https://psuite.vivo.com.cn/vbusiness`。

| 路径 | 参数与用途 |
|---|---|
| `/sync/getSyncState` | `{type:0}`，读取 `updateCount` 与 `fullSyncBefore` |
| `/sync/getSyncChunk/v2` | `{type:0,afterUsn,maxEntries:100,syncProtocolVersion:200}`；按 `chunkHighUsn` 推进，不把全局 `updateCount` 当作当页结束游标 |
| `/service/getRecentlyDeleted/v2` | `{type:0,page:1,maxEntries:100}`；独立分页读取回收站快照 |
| `/note/getIncludeItem/v2` | `{guid,syncProtocolVersion:200}`；读元数据、资源关联与版本 |
| `/note/getContent/v2` | `{guid}`；独立读取 HTML 正文 |
| `/sync/createSync/v2` | `{type:0,lastUpdateCount,noteBooks:[],notes:[新笔记],tags:[],resources:[]}` |
| `/sync/updateSync/v2` | 同上，保留原有笔记字段及未修改内容；正文未改变时不发送 `content` |
| `/note/expunge` | 移入回收站为 `{lastUpdateCount,delete:[],remove:[guid]}`；不可把 `delete` 当成普通删除 |
| `/service/recover` | `{type:0,lastUpdateCount,notes:[guid],documents:[]}` |

请求均为 POST。使用现有登录凭据与官方 `openId/token/deviceId/source/version/countryCode` 请求头。除同步状态、普通回收站操作等非加密接口外，按原版使用 `jvq_param` 封装，并解开 `jvq_response`。

加密封装使用原版生产公钥、应用标识 `com.android.notes`、协议 32、版本 1、RSA PKCS#1 v1.5 包装 AES-128 密钥及 AES-CBC/PKCS#7 正文；头部包含 CRC32。密钥和 IV 由安全随机源生成，每次请求独立配对。请求为 URL-safe Base64，真实服务端响应也可能使用标准 Base64，均已兼容。没有复用录音同步的明文 JSON 协议。

附件使用原版云盘 `fileInfo.do` 和 `getStsToken.do`，与录音下载相同的官方 HTTPS 云盘链路。只接受指定 vivo 云盘域名，不跟随重定向，不将账号 token 转发给文件域名；使用临时 STS 凭据并校验文件大小与 MD5／SHA-256。单附件上限 512 MiB。

## 本地 API

所有接口沿用本地 Bearer token。ID 为不透明摘要，不接受任意上游 URL、真实云账号标识或本地文件路径。

| 方法与路径 | 用途 |
|---|---|
| `GET /api/notes` | 当前账号索引、笔记本、自动设置、上次同步、任务及错误 |
| `POST /api/notes/sync` | 创建增量同步任务 |
| `PATCH /api/notes/settings` | `{automatic:true或false}` |
| `GET /api/notes/:id` | 正文、编辑方式、文字片段与附件列表；需要时从云端读取 |
| `POST /api/notes/create` | `{title,text}`，新建普通文本笔记 |
| `POST /api/notes/:id/rename` | `{title,version}` |
| `POST /api/notes/:id/save` | 普通文本使用 `{title,text,version}`；保留格式的文字编辑使用 `{title,edits:[{id,text}],version}` |
| `POST /api/notes/:id/trash` | `{version}` |
| `POST /api/notes/:id/restore` | `{version}` |
| `POST /api/notes/:id/attachments/:attachment/download` | 创建校验下载任务 |
| `GET /api/notes/:id/attachments/:attachment/file` | 读取已下载且匹配当前资源版本的附件 |

同步、写入和下载返回 202 与任务 ID；使用现有 `/api/jobs/:id` 和 `/api/jobs/:id/cancel` 查询与取消。同一账号串行处理同步与写入，正文读取对并发版本变更单独检查。保存错误不会推进索引或假装云端已经保存。

## 验证范围（2026-11-12）

用户明确授权后，只读检测了当前真实账号的同步状态、两页少量索引、回收站、一条普通笔记的正文及附件列表；新后端的字段归一化和正文缓存复读通过。未执行该账号全量同步、附件二进制下载，未创建、编辑、改名、删除或恢复真实笔记。临时私人响应与缓存在检测结束后删除。

85 项后端测试通过，覆盖独立原版加密向量、Base64 编码差异、分页游标、断网与异常回滚、正文读取期间的版本变化、资源缓存失效、加密笔记限制、富文本保护、字段保留、冲突、普通删除语义、回读确认、账号隔离、附件校验及 HTTP 鉴权。Qt 自检覆盖列表、搜索、锁定笔记、正文查看、禁止本地资源加载、同步任务及账号失效后清空旧资料。

云端写入与笔记附件下载目前仅做了模拟服务测试，仍需要用户在测试版中实际验证。手写与复杂原子组件的完整编辑器、笔记本管理、标签编辑、版本历史、AI 操作和跨区账号不在本次实现范围。

[脱敏验证报告](../evidence/notes/verification.json)不包含私人标题、正文、文件名、账号或令牌。[原版加密测试向量](../evidence/notes/cipher-vector.json)中的固定密钥仅用于公开测试，不是登录凭据。

## 0.1.0-12 编辑修复

旧版仅接受不带属性的 `p`／`div`／`br`，并拒绝任何有关联附件的笔记，导致手机生成的普通正文也经常无法编辑。本机缓存中复现了这一判定问题。

新版使用与原正文摘要及字符范围绑定的文字片段 ID，只替换用户实际修改的文字。原标签、属性、注释、图片和附件组件保留原字节；脚本、样式、画布、原子组件内部及 `contenteditable=false` 内容不作为可修改片段。服务器按当前正文重新校验片段 ID，拒绝未知、重复、过期或过大的修改。只改标题时不重写正文。

编辑器不显示 HTML 源码；带格式的笔记按各段文字编辑。点击保存前会提交正在输入的单元格，避免最后一段输入未保存。

修复后的 90 项后端测试及界面输入／保存自检通过。仅只读检查了现有本地缓存，未对用户云端笔记执行真实写入；云端写入仍需测试版实际验证。
